# Panel Estaciones — versión móvil

Página estática (GitHub Pages) que muestra el panel de control del grupo en el celular. **No contiene ningún dato**: al abrirla con el link compartido (que trae un código en el `#`), busca el JSON publicado por la automatización y lo dibuja. Los datos los publica el workflow `publicar-paquete` de `app-control-estaciones` cada mañana.
